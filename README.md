# Introduction to Programming

The repository of the course "Introduction to Programming" at UNI Graz.

The course is taught by Klara Venglarova. The course materials were adapted from:  https://github.com/lucijakrusic/IP23 by Lucija Brozić.

It will contain all Jupyter Notebooks and example data that we will use during the course. All notebooks will be in English.

## Usage

To use the notebooks make sure you have installed:
* Python version 3. 
* Jupyter lab (automatically installed with Anaconda, otherwise `conda install jupyterlab`)

Clone the repository from GitHub:

```bash
git clone https://github.com/kl-veng/Programming.git
```

Then change into `Programming` directory and start the Jupyter server:

```bash
cd Programming
```

```bash
jupyter lab
```

This will bring up your browser and will show you the contents of the `Programming` directory.
